# 理论笔记：压缩后的切分选择（方向 1）

起始 2026-10-13。目标：把阶段 1b / 3 观察到的规则（ZF → 7-1 + BFP5/6，MRT → 7-2 + 调制压缩；K ≤ 16 需要动态、K ≥ 32 不需要；逐 RU 的 7-2 比例随 K 上升）推成闭式条件，再用仿真验证。所有结论都在论文的框架内（负载公式的结构、ZF/MRT、服务天线选择），只是把压缩放进去。

## 1. 记号

每个 PRB 上：UE u，天线 m，服务集合 S；RU r 的服务天线 S_r（n_r = |S_r|），它服务的 UE 集合 U_r（ZF 时 U_r 为全部 U 个 UE，MRT 时为其天线所分配 UE 的并集）。理想前传下 UE u 的 SINR_u = S_u / (I_u + N)，天线 m 的发射功率 P_m。

## 2. 压缩失真进入 SINR 的方式

- **7-1**：x̂_m = x_m + e_m。块浮点误差与信号近似不相关，天线间独立，E|e_m|² = ρ(w) P_m。
  标定（oran/compression，块长 12）：ρ(w) ≈ c · 4^(−w)，c ≈ 3.5（BFP4 −18.6 dB，每多 1 bit 降 6.05 dB），与电平无关，16 bit 定点底 −86 dB。
- **7-2 + ZF**：层符号用调制压缩，无损；权值误差 ε_mu'。SE-11 中每个 (RU, UE, PRB) 的 n_r 个权值为一块，块内共用指数，所以误差方差 v_{r,u'} 由块内最大值决定（解析式见 joint.bfp_block_var）。ε_mu s_u 这一项被 UE 的 DMRS 估计吸收进有效信道，只有 u' ≠ u 的泄漏是干扰。
- **7-2 + MRT**：RU 用本地 SRS 自算权值，不经前传，无失真。

于是
  SINR_u^c = S_u / (I_u + N + D_u)，
  D_u = Σ_{r∈7-1} ρ(w_r) Σ_{m∈S_r} |h_um|² P_m + Σ_{r∈7-2,ZF} Σ_{u'≠u} v_{r,u'} Σ_{m∈S_r} |h_um|²。

**命题 1（压缩等效为 SINR 上限）。** 定义相干增益比 G_u = S_u / Σ_{m∈S} |h_um|² P_m，即相干合成的信号功率与非相干功率和之比。全网 7-1、同一宽度 w 时
  1 / SINR_u^c = 1 / SINR_u + ρ(w) / G_u，
即压缩把 SINR 封顶在 G_u / ρ(w)。ZF 在 i.i.d. 近似下 G ≈ (|S| − U + 1) / U。7-2 + ZF 的形式相同，只是 ρ(w) 换成 ρ_w(b, n_r) · ψ · (U−1)/U，其中 ψ 为块内峰均比带来的放大。

**推论 1（所需位宽）。** 要让 UE u 的 SINR 不低于目标 SINR_t（< SINR_u），需要
  ρ(w) ≤ G_u (1/SINR_t − 1/SINR_u)，即 w ≥ ½ log₂( c / (G_u (1/SINR_t − 1/SINR_u)) )。
MCS 截顶时，若 SINR_u 高于封顶值（单层 7.41 bit/s/Hz 对应约 22.3 dB），SINR_t 可以取封顶值，余量越大所需位宽越小；这解释了 MCS 口径下 BFP5–6 就够、而 Shannon 口径下需要 BFP8–9。

## 3. 每个 RU 的负载（论文公式的结构，加上压缩）

每 PRB 每时隙的净荷比特（168 = 14 符号 × 12 子载波）：
  L71_r = n_r · 168 · (2w + 2/3)                                  （BFP：每 12 个 RE 一个 8 bit 指数）
  L72_r = 168 Σ_{u∈U_r} Qm_u + [ZF] |U_r| (2 b n_r + 24)          （调制压缩 Qm bit/RE；SE-11 每块 2b n_r + 8 bit，加 16 bit beamId）
报头和上行 CI 是小量，先略去，验证时再看偏差。

**命题 2（ZF 下的切换门限）。** U_r = U、Qm 相同时，7-2 的负载更小当且仅当
  n_r > n* = U (168 Qm + 24) / (168 (2w + 2/3) − 2 b U)。
例：U = 10、Qm = 8、w = b = 6 时 n* ≈ 6.8；U = 20 时 n* ≈ 14.3；U = 5 时 n* ≈ 3.3。

**推论 2（MRT 下 7-2 总是更省）。** RU 本地算权值时 L72_r = 168 Σ_{u∈U_r} Qm_u ≤ 168 · 8 · |U_r| ≤ 168 · 8 · n_r < n_r · 168 (2w + 2/3)（w ≥ 4），所以任何 K、任何宽度下 7-2 都不差于 7-1。

**推论 3（不压缩时退化为论文）。** w = 16、7-2 层符号也用 32 bit、不计权值时 n* = U：RU 的服务天线数超过 UE 数时 7-2 更省，这就是论文的结论（论文另有 γ 常数）。压缩把门限乘上 Qm / (2w + 2/3)：256QAM、w = 6 时约 0.63，QPSK、w = 4 时约 0.23。

**推论 4（为什么仍需要动态）。** n* 随状态变化：高 SINR 时 Qm = 8、w ≈ 5–6，n* ≈ 0.6–0.7 U；低 SINR 时 Qm 降到 2–4、w 降到 4，n* ≈ 0.2–0.4 U。服务天线数 n_r 落在两者之间的 RU 必须随状态切换切分；n_r 全部大于 n*_max（大 K）或全部小于 n*_min 时，固定切分就够了。

## 5. 检验结果（2026-10-13，S4 / S4b / S4c，MCS 截顶）

1. **命题 2 与推论 2 完全成立。** 重建阶段 3 中 P 与 B2 的逐撒点选择（30 个撒点 × 9 个状态 × 7 个 K，共 44036 个 RU 决策）：给定所选位宽，命题 2 的门限 n* 对切分的预测与优化器 100% 一致（ZF：n_r > n* 才选 7-2；MRT：全部选 7-2）；用含报头和 CI 的精确负载比较也是 100% 一致。ZF 下选 7-2 的 RU 从 K ≤ 4 的 0% 增加到 K = 8 的 9%、K = 16 的 28%、K = 32 的 55%、K = 64 的 100%，全部是 n_r > n* 的 RU。
2. **"负载感知服务集合"不是收益来源，之前的机理猜测（把天线集中到少数 RU）不成立。** P 用的服务天线更少（ZF：K = 1 时 24.8 对 28.2 根），激活 RU 数和 n_r 反而略小；MRT 下每个 RU 服务的 UE 数与 B2 几乎相同。消融（S4b）表明收益来自"每步加和速率增量最大的天线"这种贪心本身：只看和速率增量的路径与负载感知路径正面比较，K ≥ 4 时前者更好（K = 8 时负载感知在 50% 的撒点更差、8% 更好）。三条路径取最好时，相对论文路径的节省主要由和速率贪心贡献。由于"论文路径"是我们对论文 [10] 的 ZF-H / MRT-H2 的近似，这部分收益在忠实实现 [10] 之前不能算作贡献。
3. **闭式策略接近优化器。** 和速率贪心选服务集合 + 全网一个位宽 + 命题 2 的逐 RU 切分（S4c），负载比同一路径上的逐 RU 拉格朗日优化器高：K = 1 时 6.7%、K = 2 时 4.9%、K = 4 时 3.2%、K = 8 / 16 时约 2%、K = 32 时 0.6%、K = 64 时 −0.4%。剩余差距在小 K：单天线 RU 很多、各自对失真的贡献差别很大，优化器给不同 RU 不同位宽。

## 6. 下一步：命题 3（逐 RU 位宽的注水分配，待推导验证）

线性化后，7-1 RU 的负载对位宽的斜率为 2·168·n_r（每 PRB 每时隙），失真为 ρ(w) G_r，其中 G_r = Σ_{b,u} g_bu Σ_{m∈S_r} |h_um|² P_m 是和速率加权的非相干贡献，ρ(w) = c·4^(−w)。拉格朗日驻点给出
  w_r = w₀ + ½ log₂(G_r / n_r)，
即每根天线的加权贡献每增加 3 dB，多给半个比特。7-2 权值同理，b_r = b₀ + ½ log₂(G'_r / (U n_r))，且两族共用同一个乘子，因此 b_r − w_r ≈ ½ log₂(168 (U−1) ψ / U²)（ψ 为权值块峰均比因子；U = 10 时权值约多 2 bit，因为每 bit 权值的负载远小于每 bit 数据）。若"和速率贪心服务集合 + 命题 3 的位宽 + 命题 2 的切分"能追平优化器，整个联合问题就分解为三个闭式步骤。

## 7. 服务集合按 [10] 忠实实现（S5，2026-10-13）

[10] = Girycki 等，"Learning-Based Precoding-Aware Radio Resource Scheduling for Cell-Free mMIMO Networks"，IEEE TWC 23(5)，2024（Zotero 7RI5L52H）。实现见 `heuristics10.py`：MRT 用算法 1（AP 只服务最强 UE、按最强/次强功率比排序、两轮选择、P_offset = 23 dB）；ZF 用算法 2 的顺序（按 UE 轮流取第 i 强 AP）加 EuCNC 的"能提高和速率才加入"。与 [10] 的差别：服务集合对所有 PRB 相同（[10] 逐 PRB 选），ZF 归一化沿用阶段 0。

- **复现**：ZF 与阶段 0 几乎相同（10 UE、−90 dBm：29 根、125.7，论文 127）。MRT 在 −90 dBm 有改善（5 UE 53.2，之前 49.6），但 −50 dBm 仍比论文低约 30%（5/10/20 UE：9.7/15.5/22.5，论文 14/22/33）。这个差距与选天线算法无关，原因可能是 [10] 逐 PRB 选 AP 带来的频率分集，或 [10] 式 (6) 的宽带 SINR 定义；未查明。
- **服务集合对比**（MCS，三条路径都可行的 652 个状态-撒点）：近似论文路径比 [10] 差 0.5–6.5%；和速率贪心比 [10] 好 2.7–6.2%，但每步要算全部候选的和速率，计算量高一个量级，且与前传无关。结论：服务集合不作为贡献，后续用 [10] 的算法。

## 12. 忠实口径与 1024QAM 下的检验（S12、S13，2026-10-13）

- **命题 3 + 命题 2 仍与优化器持平**（S12，逐撒点 P1 负载相对逐 RU 拉格朗日优化器）：MCS 表 2 下 −0.4% 到 +0.1%，表 4（1024QAM）下 −0.4% 到 0.0%，两种服务集合都是如此。全网一个位宽在 K = 1 时多出 6.0%（表 2）/ 7.2%（表 4），ZF 状态 +9.0% / +10.1%。
- **边界预测**（S13，S8 方法）：K* = 43.6（忠实口径、表 2）、39.1（1024QAM）；对应 S10 / S11 中 K = 32 的动态收益 8.5% / 7.5%，K = 64 的 0.4% / 1.4%。1024QAM 下高 SNR 状态 Q̄m ≈ 10，但所需位宽也升高（τ ≈ 7），两者部分抵消，K* 略降。
- **真实编解码器复核**（每个 K ∈ {1, 4, 16, 64}、9 个状态各 20 个撒点，剔除无效撒点后 716 个）：S10 预测 0.9875、实测 0.9882；S11 预测 0.9865、实测 0.9870；低于 0.98 的占 4.6% / 4.7%，最低 0.976 / 0.977。
- 附带观察：忠实口径下和速率贪心选服务集合比 [10] 省得更多（K = 1 时 3.94 对 4.50 Gbit/s），但这与前传无关，仍不作为贡献。
