# 命题与证明（压缩后的切分选择）

整理日期：2026-10-13。数值验证见 `theory_notes.md` 第 5–9 节与 `experiments.md` 的 S4–S11。本文只写陈述、假设和证明。

## 0. 模型与假设

网络与论文（Girycki 等，EuCNC 2024）相同：N 根单天线 AP，每 K 根组成一个 RU；U 个单天线 UE；每个 PRB 上做 ZF 或 MRT；服务集合 S，RU r 的服务天线 S_r（n_r = |S_r|）与服务 UE U_r（ZF 时 U_r = 全部 U 个 UE）。每个 PRB 一个时隙内有 168 = 14 × 12 个 RE。

- **A1（压缩误差）** 7-1 的 U-plane 采用块浮点（BFP，每 PRB 每符号 12 个 RE 为一块），误差 e_m 零均值、与信号不相关、天线间独立，E|e_m|² = ρ(w) P_m，ρ(w) = c·4^(−w)。依据：oran/compression 的 BFP 实测，块长 12 时 c ≈ 3.5（BFP4 为 −18.6 dB，每增加 1 bit 降 6.05 dB），与电平无关，直到 16 bit 定点底 −86 dB。
- **A2（调制压缩）** 7-2 的层符号用调制压缩（O-RAN CUS 附录 A.5），无损，每 RE Qm bit。
- **A3（权值误差）** 7-2 + ZF 时，权值经 SE-11 下发，每个 (RU, UE, PRB) 的 n_r 个权值为一块做 BFP。按 BFP 规则（块内最大值决定指数 e），误差在 ±2^e/2 内均匀分布，方差 v = 2·4^e/12（复数），块间独立。
- **A4（接收机）** UE 通过 DMRS 估计每个 PRB 上的有效增益，等价于对该 PRB 的 RE 做 LMMSE。
- **A5（负载）** 采用论文负载公式的结构（每 RE 速率 × 每 RE 比特 × 流数），并按 O-RAN 消息格式计每 PRB 每时隙的净荷：
  - 7-1：L71_r = n_r · 168 · (2w + 2/3)（每 12 个 RE 一个 8 bit 指数）；
  - 7-2：L72_r = 168 Σ_{u∈U_r} Qm_u + [ZF] |U_r| (2 b n_r + 24)（SE-11 每块 2 b n_r + 8 bit，加 16 bit beamId）；
  - 报头与上行 CI 视为小量（数值上 < 2%）。

记号：S_u、I_u、N_u 分别为 UE u 在理想前传下的信号、干扰、噪声功率（逐 PRB），SINR_u = S_u / (I_u + N_u)。

## 1. 命题 1（压缩等效为 SINR 上限）

在 A1–A4 下，UE u 的有效 SINR 为
  SINR_u^c = S_u / (I_u + N_u + D_u)，
  D_u = Σ_{r∈7-1} ρ(w_r) Σ_{m∈S_r} |h_um|² P_m  +  Σ_{r∈7-2,ZF} Σ_{u'≠u} v_{r,u'} Σ_{m∈S_r} |h_um|²。
特别地，若全部 RU 为 7-1 且位宽同为 w，定义相干增益比 G_u = S_u / Σ_{m∈S} |h_um|² P_m，则
  SINR_u^c = S_u / (I_u + N_u + ρ(w) S_u / G_u)；ZF（I_u = 0）时 1/SINR_u^c = 1/SINR_u + ρ(w)/G_u。

**证明。**
- 7-1 RU：发送 x̂_m = x_m + e_m，接收 y_u = Σ_m h_um x_m + Σ_m h_um e_m + n_u。由 A1，第二项与信号不相关、零均值，方差为 Σ_m |h_um|² ρ(w_r) P_m。
- 7-2 + ZF RU：发送 x̂ = Σ_{u'} (w_{u'} + ε_{u'}) s_{u'}，接收 y_u = Σ_{u'} (h_u w_{u'} + h_u ε_{u'}) s_{u'} + n_u。u' = u 的一项 h_u ε_u 是该 PRB 上有效信道的固定扰动，由 A4 被 UE 的增益估计吸收，不构成干扰；u' ≠ u 的各项由 A3 零均值、相互独立，方差为 Σ_{m∈S_r} |h_um|² v_{r,u'}。
- 由 A4，LMMSE 下的有效 SINR 为信号功率除以其余所有不相关分量的功率之和，即得 D_u 的表达式。
- 全部为 7-1、同一 w 时，D_u = ρ(w) Σ_m |h_um|² P_m = ρ(w) S_u / G_u；ZF 时 I_u = 0，两边取倒数即得。∎

**推论 1（所需位宽）。** ZF 下要求 SINR_u^c ≥ SINR_t（SINR_t < SINR_u），则需
  ρ(w) ≤ G_u (1/SINR_t − 1/SINR_u)，即 w ≥ ½ log₂( c / (G_u (1/SINR_t − 1/SINR_u)) )。
MCS 截顶时 SINR_t 取 UE 当前 MCS 档位的下沿：SINR_u 高于最高档位越多，所需 w 越小。

## 2. 命题 2（每个 RU 的切分门限）

在 A2、A5 下，设 ZF（U_r = U）、7-1 的 U-plane 位宽为 w、7-2 的权值位宽为 b、UE 的平均调制阶数为 Q̄m。若 168 (2w + 2/3) > 2bU，则
  L72_r < L71_r  ⟺  n_r > n* = U (168 Q̄m + 24) / (168 (2w + 2/3) − 2 b U)。

**证明。** L71_r − L72_r = n_r [168 (2w + 2/3) − 2bU] − U (168 Q̄m + 24)。方括号为正时，它关于 n_r 单调递增，零点即为 n*。∎

**推论 2（MRT 下 7-2 不劣）。** MRT 时权值在 RU 本地计算，L72_r = 168 Σ_{u∈U_r} Qm_u。由于 |U_r| ≤ n_r（每根天线只服务一个 UE）且 Qm ≤ 8（MCS 表 2）或 10（表 4），对任意 w ≥ 4 有
  L72_r ≤ 168 Q_max n_r < 168 (2w + 2/3) n_r = L71_r。
其中 Q_max = 10 时要求 2w + 2/3 > 10，即 w ≥ 5：1024QAM 且 w = 4 时这一推论可能不成立。

**推论 3（退化为论文）。** 不压缩时（7-1 每 RE 32 bit，7-2 层符号每 RE 32 bit，不计权值），n* = U：服务天线数超过 UE 数的 RU 用 7-2 更省，这就是论文的结论（论文另有 γ 常数）。压缩把门限乘上约 Q̄m / (2w + 2/3)。

**推论 4（为什么仍需动态）。** n* 随状态变化：Q̄m 随 SNR 降低而减小；w、b 由推论 1 决定；U 随负载变化。若某个 RU 的 n_r 落在 [min_s n*(s), max_s n*(s)] 之间，它的最优切分就随状态改变。

## 3. 命题 3（逐 RU 位宽的注水分配）

把和速率对失真线性化：ΔSE ≈ −Σ_r g_r ρ(w_r)，其中 g_r = Σ_{b,u} (∂SE/∂D_{bu}) Σ_{m∈S_r} |h_um|² P_m（7-2 权值同理，记 g'_r）。考虑松弛问题
  min_{w_r} Σ_r a_r w_r   s.t.   Σ_r g_r c 4^(−w_r) ≤ Δ，
其中 a_r 为负载对位宽的斜率：7-1 为 336 n_r，7-2 权值为 2 n_r U（均按每 PRB 每时隙计）。最优解为
  w_r = t + ½ log₂(g_r / a_r)，
t 为全网同一个标量，由约束取等号确定。

**证明。** 目标关于 w_r 线性；4^(−w_r) 是凸函数，所以约束集是凸集，问题为凸问题，KKT 条件充分。对拉格朗日函数 Σ a_r w_r + μ (Σ g_r c 4^(−w_r) − Δ) 求导：a_r − μ c ln4 · g_r 4^(−w_r) = 0，所以 4^(−w_r) = a_r / (μ c ln4 · g_r)，即 w_r = ½ log₂(μ c ln4 / 1) + ½ log₂(g_r / a_r)。记 t = ½ log₂(μ c ln4)，得证。t 关于 Δ 单调，可一维搜索。∎

**说明。**
- 每个 RU 的"和速率加权的非相干贡献"每增加 3 dB（相对它的负载斜率），就多分半个比特。7-1 与 7-2 共用同一个 t，所以 b_r − w_r = ½ log₂((g'_r / (2 n_r U)) / (g_r / (336 n_r)))；U = 10 时权值约多 2 bit，因为每 bit 权值的负载远小于每 bit 数据。
- 实际取整并限制在 4..12，切分再按命题 2 用各自位宽选择。数值上与逐 RU 枚举的拉格朗日优化器相差 −0.4% 到 0.0%（S6）。

## 4. 命题 4（动态切分失效的 K 边界）

设 ZF 状态 s 的服务天线数为 M̂(s)，激活的 RU 都是 N/K 个，并且服务天线在激活 RU 间均匀分布，即 n_r ≈ M̂(s) K / N。若对所有 ZF 状态都有 M̂(s) K / N > n*(s)，则所有 RU 在所有状态下都选 7-2（MRT 状态由推论 2 保证），切分不随状态变化。由此
  K* = max_{ZF 状态 s} N n*(s) / M̂(s)：
K ≥ K* 时固定 7-2 即为最优切分；K < K* 时至少有一个 ZF 状态需要 7-1，而 MRT 状态需要 7-2，切分必须随状态切换。

**证明。** 由命题 2，ZF 状态下 n_r > n*(s) 的 RU 选 7-2；由推论 2，MRT 状态下所有 RU 选 7-2。代入 n_r ≈ M̂ K / N 即得条件。K < K* 时存在某个 ZF 状态 s 使得 n_r < n*(s)，该状态需要 7-1。∎

**说明。** 实际的 n_r 在 RU 间不均匀，所以门限附近会出现"部分 RU 选 7-2"。用服务集合的 n_r 分布计算 P(n_r > n*(s))，与 S7 观察到的比例吻合（S8）。论文场景、MCS 表 2 下，K* ≈ 46（S8），与 S7 中 K = 32 时动态收益 10.8%、K = 64 时 0.8% 一致。
