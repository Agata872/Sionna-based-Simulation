# Validation 实验索引

研究问题：在每个 PRB 上，活跃天线数、总发射功率、每 AP 功率上限和参与传输的 UE 集合都固定时，从整 AP 选择扩展到逐天线选择能增加多少 sum SE。锚点论文：Girycki 等，IEEE TWC 23(5) 2024（[10]）。

代码：
- `antsel.py`：按 AP 预计算各天线子集的复数接收幅度，再组合成完整候选（与直接穷举等价）。
- `test_antsel.py`：验收检查，运行 `python test_antsel.py`。
- `run_round1.py`：第一轮仿真。
- `antsel_zf.py`：ZF/RZF 参照（所有活跃天线联合服务全部 UE，式 (18) 式统一缩放，两种功率约束）。
- `test_round2.py`：第二轮验收（非理想 CSI 的 MRT、最强 UE 映射、ZF/RZF 均与直接穷举逐样本核对）。
- `run_round2.py`：第二轮仿真（`--exp mapping` / `--exp precoder`）。
- `run_all.sh`：一键运行 E2–E5（在 herdr 面板中运行）；日志 `results/run_all_20261119.log`，状态 `results/run_all_20261119.status`。
- `zfsel.py`：第二轮受控 ZF（cell_free_round2_zf_simulation.txt）：A/B/C/Ceq 与匹配 MRT 候选集合的对照。
- `test_zfsel.py`：受控 ZF 验收（对角矩阵验算、误差模型、M = 1 相等、不等式、M = 2 逐候选直接伪逆、并列规则、复共轭约定）。
- `run_zf_controlled.py`：受控 ZF 仿真；`plot_zf_controlled.py`：作图。
- `same_total.py`：E8 同总天线数场景（16 根天线的布局、M.2135 UMi 大尺度、各 K 的 RU 分组、全部子集的 ZF 穷举、M̂）。
- `test_same_total.py`：E8 验收；`run_same_total.py`：E8 仿真；`plot_same_total.py`：E8 作图。

## E1 第一轮 MRT（round1_mrt_20261119）

- 目的：在受控设定下比较 A（AP 级穷举）、B（穷举每 AP 激活数，按服务链路 |h|² 取最强天线）、C（天线级穷举）。
- 设定：N = 3 AP、U = 2 UE。AP 1、AP 2 固定服务 UE 1，AP 3 固定服务 UE 2。M = 1, 2, 4, 6，K = 2M，P_total = 2，P_max = 1，p[n] = P_total·|S[n]|/K。服务链路 β = 1，干扰链路 β ∈ {0.05, 0.25, 0.8}，SNR ∈ {0, 10, 20, 30} dB，每组 1000 个样本。每 AP 用单位范数 MRT，同一数据流先加复数幅度。
- 随机数：样本 s 用 `default_rng([20261119, s])` 生成 M = 8 的信道，再取前 M 根；A/B/C 与 12 组 (β, SNR) 共用同一样本。每组参数各自求 argmax。
- 验收（运行前已通过）：4 AP 确定性例子 A = 4.2309544348、C = 8.7846348456；C 的可行候选数为 2/14/494/18563/735470（M = 1/2/4/6/8）；M = 2 时快速算法与直接穷举逐样本一致（最大差 4e-14）；M = 1 时 A = B = C 逐位相等；C ≥ B ≥ A。
- 命令：`python run_round1.py --M 1 2 4 6 --samples 1000 --workers 48`
- 结果目录：`results/round1_mrt_20261119/`，包括 metadata.json、src/、rows.jsonl、samples_M*.npz、summary.md 和 run.log。
- 状态：完成（2026-11-19）。48 进程下，M = 1/2/4/6 分别耗时 0.2/0.2/0.2/1.0 s。M = 8 的候选数约为 M = 6 的 40 倍，估计约 40 s。
- 运行检查：全部 1000 × 12 × 4 个（样本 × 参数 × M）组合都满足 C ≥ B ≥ A，没有违反；M = 1 时 A = B = C 逐位相等；没有不可行样本（映射固定，AP 3 总能服务 UE 2）。
- 结论（平均差值，单位 bit/s/Hz，按 M = 2/4/6 列出，95% 配对 t 区间半宽均不超过 0.16）：

  | β | SNR | B−A | C−B | C−A | C−A % (M=6) |
  |---|---|---|---|---|---|
  | 0.05 | 0 | 0.23 / 0.35 / 0.43 | 0.00 / 0.00 / 0.00 | 0.23 / 0.35 / 0.43 | 7.7 |
  | 0.05 | 30 | 1.05 / 1.61 / 1.78 | 0.72 / 2.50 / 4.00 | 1.77 / 4.10 / 5.79 | 36.1 |
  | 0.8 | 0 | 0.38 / 0.55 / 0.60 | 0.06 / 0.12 / 0.23 | 0.43 / 0.67 / 0.83 | 17.8 |
  | 0.8 | 30 | 1.26 / 2.19 / 2.59 | 0.93 / 3.46 / 6.15 | 2.19 / 5.65 / 8.74 | 101.6 |

  1. 天线级增益没有随 M 减小。在每组 (β, SNR) 下，C−A 的绝对值都随 M 增大。噪声受限时（β = 0.05、0 dB），C−B ≈ 0，C−A = B−A，相对增益稳定在约 7.5%，与顺序统计量的估计一致（M = 6 时能量比 1.35）。
  2. B−A（重新分配激活数，并按服务链路强度挑天线）在全部设定下为 0.2–2.6 bit/s/Hz。
  3. C−B 只在低 SNR 且干扰弱时可以忽略。它随 SNR、β 和 M 迅速增大，在高 SNR 下占 C−A 的大部分（β = 0.8、30 dB、M = 6 时为 6.15 / 8.74）。这部分收益来自在几万个子集里组合搜索泄漏近似抵消的子集：它依赖所有干扰链路的精确瞬时 CSI，和 ZF 的前提相同；它随 M 增长，反映的是候选数的指数增长。因此判断"干扰感知选天线"是否值得做，应与同一组活跃天线上的 ZF/RZF 比较，并检查非理想 CSI 下还剩多少。
  4. 诊断：M = 6 时，C 几乎总是同时使用 AP 1 和 AP 2（≥ 99.7%）。在这些样本里，k3 = M 只占 4–17%，大多数解同时减少了 AP 3 的天线。B 同时使用两个 AP 的比例为 82–100%，其中 k3 < M 占 65–83%。低 SNR 下 C 最常选 (3,4,5)/(4,3,5)，高 SNR 下最常选 (4,4,4)。

## E3 第二轮 (a) 最强 UE 映射（round2a_mapping_20261119）

- 目的：改用原文规则，每个 AP 服务其完整信道 ‖h[u,n,:]‖² 最大的 UE，A/B/C 共用映射；报告无法让两个 UE 都获得服务的样本比例，三种方案在相同的可行样本上比较。
- 设定：β 矩阵沿用第一轮的名义布局（AP 1、AP 2 靠近 UE 1，AP 3 靠近 UE 2）；映射逐样本、逐 β 生成；M = 1, 2, 4, 6, 8；其余同 E1。
- 命令：`python run_round2.py --exp mapping --M 1 2 4 6 8 --samples 1000 --workers 48`
- 状态：完成（2026-11-19，run_all.sh，各 M 合计约 31 s）。没有违反 C ≥ B ≥ A 的样本。
- 结论：
  1. 不可行比例（三个 AP 都选同一个 UE）：β = 0.05 时为 5.3%/0.6%/0（M = 1/2/≥4），β = 0.25 时为 17%/9.3%/4.3%/1.6%/0.3%（M = 1/2/4/6/8），β = 0.8 时各 M 都约 20–24%。β = 0.8 时 67–82% 的样本映射与名义映射不同。
  2. 在可行样本上，C−A 与 C−B 和固定映射（E1/E2）几乎相同（例如 M = 6、β = 0.8、30 dB 时为 8.73 / 6.07，固定映射为 8.74 / 6.15）。A 本身因映射更好而略升。第一轮的结论不依赖固定映射。注意这里只比较可行样本，样本集合与 E1/E2 不完全相同。

## E4 第二轮 (b) ZF/RZF 参照（round2bc_precoder_csi_20261119，eps = 0 的行）

- 目的：判断 MRT 的 C−B 是否只是 MRT 本身的弱点：比较 AP 级 ZF/RZF 与天线级 MRT，并给出 ZF/RZF 下的天线级增益 C−A。
- 设定：所有活跃天线联合服务两个 UE；W = H_S^H (H_S H_S^H + αI)^{-1}，ZF α = 0，RZF α = Uσ²/P_total；按 [10] 式 (18) 统一缩放，由最吃紧的约束决定。式 (18) 在 M > 1 时的两种推广都跑：`ant` 每根活跃天线 ≤ P_max/M（M = 1 时即原式），`ap` 每 AP ≤ P_max，两者都受总功率 P_total 约束。A = 任选 K/M 个整 AP（ZF 不需要映射，含 AP 1 + AP 2），C = 任选 K 根天线；按实际 sum SE 选最优。同一样本上同时算 MRT A/B/C，可逐样本配对。
- 命令：`python run_round2.py --exp precoder --M 1 2 4 6 8 --samples 1000 --workers 48`（与 E5 同一次运行）
- 状态：完成（2026-11-19，run_all.sh，precoder M = 8 耗时 2350 s）。ε = 0 的 MRT 与 E1/E2 逐位一致，理想 CSI 下所有 C ≥ A 检查都通过。
- 结论：
  1. 高 SNR 或强干扰时，AP 级 ZF/RZF 远好于天线级 MRT。ZFap_A − MRT_C 在 β = 0.8、30 dB 时为 14.7/11.9/9.1/6.6（M = 2/4/6/8），在 β = 0.05、30 dB 时为 6.6/4.5/2.9/1.9。MRT 在这一区域的大 C−B 主要是在弥补 MRT 本身的弱点：只要换成 ZF，就能消除干扰并得到更高的 sum SE。差距随 M 缩小，因为组合搜索能抵消的泄漏随候选数增多。
  2. 低 SNR、弱干扰时（β = 0.05、0–10 dB），天线级 MRT 是最好的方案：MRT_C 比 AP 级 ZF/RZF 高 0.2–0.8，比天线级 RZF 在 0 dB 时也高 0.09–0.20，在 10 dB 时低约 0.2。这一区域 C−B ≈ 0，收益全部来自 B−A。
  3. ZF/RZF 下的天线级增益 C−A：逐 AP 约束时为 0.26–0.83 bit/s/Hz（1.6–14.5%），逐天线约束时为 0.20–1.21（2.1–19.7%）。C−A 随 β 增大，在 β = 0.8 时随 M 略增，几乎不随 SNR 变化，所以相对增益在低 SNR 最大。逐天线约束的绝对 SE 明显更低（M = 8、β = 0.05、0 dB 时 ZFant_A 3.87，ZFap_A 6.15），因为单根天线的功率上限成了瓶颈；也正因为如此，天线级选择在逐天线约束下收益更大。
  4. 理想 CSI 下 RZF ≈ ZF（高 SNR 时差 < 0.02），只在低 SNR 时 RZF 更好。

## E5 第二轮 (c) CSI 误差（round2bc_precoder_csi_20261119，eps > 0 的行）

- 目的：检查 C−B（组合式泄漏抵消）在非理想 CSI 下还剩多少，并在同一 CSI 下比较 ZF/RZF。
- 设定：ĥ = h + e，e[u,n,m] ~ CN(0, ε·β[u,n])，NMSE ε ∈ {10⁻³, 10⁻², 10⁻¹}（−30/−20/−10 dB），误差样本 `default_rng([20261119, s, 1])`，各 ε、β、SNR 共用。选择、B 的天线排序、MRT/ZF/RZF 权值和缩放因子都用 ĥ，sum SE 用真实 h 评估；因此非理想 CSI 下 C ≥ A 不再必然成立。
- 命令：同 E4
- 状态：完成（与 E4 同一次运行）。
- 结论（相对于 ε = 0，C−B 的保留比例）：
  1. MRT 的 C−B 对 CSI 误差敏感。高 SNR（30 dB）时，NMSE −30 dB 保留 93–100%，−20 dB 保留 69–91%，−10 dB 只保留 31–54%（M = 8、β = 0.8 时 8.53 → 2.61）。低 SNR 时 C−B 本来就小，保留 71–100%。
  2. MRT 的 B−A（重新分配激活数，按服务链路强度挑天线）对 CSI 误差稳健。例如 M = 8、β = 0.05、0 dB 时 C−A 为 0.49 → 0.48（−10 dB），C−B 始终 ≈ 0。
  3. ZF/RZF 本身也会因 CSI 误差出现残余干扰，但在高 SNR 下通常仍优于天线级 MRT。RZFap_A − MRT_C 在 −10 dB 时为 1.0–4.0（M = 4/6/8、β = 0.8），只有 M = 8、β = 0.05、30 dB 时持平（−0.20）。
  4. ZF/RZF 的天线级增益 C−A 对 CSI 误差稳健：β = 0.8 时，M = 8 在各 ε 下都约为 0.78，M = 6 为 0.61–0.82；β = 0.05、30 dB 时从约 0.43 降到 0.24–0.33。
- 总体判断（E1–E5）：
  - 在 MRT 适用的区域（低 SNR、弱干扰），天线级选择的收益是 B−A，约 0.23–0.49 bit/s/Hz（约 7.5%）。它对映射和 CSI 误差都稳健，低复杂度的 B 已经能完全拿到。
  - 高 SNR 时 MRT 的大 C−B，依赖理想 CSI 下的组合式泄漏抵消，而且被 AP 级 ZF/RZF 全面超过，因此不值得为 MRT 设计干扰感知的选天线算法。
  - ZF/RZF 下的天线级增益（0.2–1.2 bit/s/Hz，约 2–20%）稳定且对 CSI 误差稳健，是更值得追的方向；这一轮还没有检验低复杂度选择（ZF 版的 B）能拿到其中多少。

## E6 第二轮受控 ZF（round2_zf_controlled_20261120）

- 目的：按 cell_free_round2_zf_simulation.txt，在同一 ZF 预编码器下回答：(1) 整 AP 与逐天线选择差多少；(2) 匹配实际发射功率后还剩多少（Ceq），简单排序（B）能拿到多少；(3) 估计 CSI 下真实信道上还剩多少。
- 设定：N = 3、U = 2、M = 1, 2, 4, 6、K = 2M；UE 1 → [1, 1, β_cross]，UE 2 → [β_cross, β_cross, 1]，β_cross ∈ {0.05, 0.25, 0.8}；SNR 0/10/20/30 dB；P_total = 2、P_max = 1；每组 1000 个样本。集中式 ZF，所有活跃天线服务两个 UE；c2 = min(P_total/Q, P_max/max q[n])，P_used = c2·Q。A = 两个完整 AP（含 AP 1 + AP 2），B = 穷举各 AP 活跃数 + 按估计 Σ_u|Ĥ|² 取最强，C = 全部 K 子集，Ceq = 以 P_ref = P_used(A) 恰好发送且各 AP 不超上限的 C 候选。选择一律按估计 sum SE（等价于按 c2），并列取字典序最小的候选。
- CSI：ĝ = (1−ε)g + √(ε(1−ε))·e（集合 NMSE = ε），ε ∈ {0, 10⁻², 10⁻¹}；e 来自独立流 `default_rng([20261119, s, 1])`。真信道沿用第一轮样本 `default_rng([20261119, s])`。与 E5 的误差模型（ĝ = g + √ε·e）不同，两者分开汇报。
- 对照：要求 AP 3 至少一根天线激活的 A_AP3、C_AP3（与 MRT 候选集合匹配），以及同一样本、同一 CSI 下的 MRT A/B/C（MRT 实际功率恒为 2）。
- 复用：完美 CSI 的 A/C 与 E4 的 ZFap_A/ZFap_C 逐样本核对，MRT 完美 CSI 与 E1/E2 核对，核对结果写在 metadata.json 的 `reuse` 中。约定 H = conj(h)；ZF 对整体共轭不变，所以与试跑的 H = h 结果逐样本相同。
- 验收（运行前已通过，`test_zfsel.py`）：对角矩阵 sum SE = 6.9188632373（q = [1, 0.25]，c2 = 1，P_used = 1.25，单 AP 上限先生效）；M = 1 时 A = B = C = Ceq；估计 SE 满足 C ≥ B ≥ A、C ≥ Ceq ≥ A；M = 2 时快速实现与直接伪逆逐候选一致。
- 命令：`python run_zf_controlled.py --M 1 2 4 6 --samples 1000 --workers 48`；作图 `python plot_zf_controlled.py`（fig_gain_M4/M6/M8、fig_power）
- 状态：完成（2026-11-20，12 s）。运行时检查：功率越界 0、活跃天线数错误 0、Ceq 功率一致性误差 ≤ 2.4e-13、估计信道 ZF 非对角残差 ≤ 1.9e-13、秩不足候选 0，任何样本都没有违反估计 SE 的不等式（完美 CSI 下的真实 SE 也没有）。复用核对：完美 CSI 的 A/C 与 E4 的 ZFap_A/ZFap_C 最大差 2.8e-14，MRT 与 E1 逐位一致。实测 NMSE：0.0098–0.0100（−20 dB）、0.098–0.100（−10 dB）。
- 结论（真实信道上的逐样本配对均值，bit/s/Hz；M = 2–8 含 E7，重点 M = 4、6）：
  1. 统一为 ZF 后，整 AP 与逐天线选择的差距（完美 CSI）：C−A = 0.26–0.83（1.6–14.5%），其中 M = 4、6 为 0.34–0.82，95% 区间半宽 ≤ 0.03。M ≥ 4 时 99–100% 的样本 C−A > 0（M = 2 时 81–90%）。β_cross ≥ 0.25 时中位数 ≈ 均值；β_cross = 0.05 时中位数只有均值的 0.54–0.65 倍，收益偏向部分样本。C−A 随 β_cross 增大，几乎不随 SNR 变化，所以相对增益在 0 dB 最大（6.0–14.5%），30 dB 时只有 1.6–3.2%。
  2. 功率：A 在 100% 的样本中由单 AP 上限决定缩放，P_used(A) = 1.62–1.85。C 用 1.77–2.00，单 AP 上限起作用的比例在 β_cross = 0.05 时为 74–85%，0.8 时为 3–43%。同功率对照 Ceq−A = 0.09–0.57，保留 C−A 的 37–73%（M = 4、6 约 55–70%）；其余部分来自多用了功率预算，即缓解单 AP 瓶颈。例如 M = 6、β_cross = 0.8 时，C 的 Q 比 A 低 0.75 dB（信道求逆效率，Ceq 也拿得到），功率多 0.43 dB（只有 C 拿得到）。
  3. 简单排序：B−A 占 C−A 的 84–98%，完美 CSI 下 C−B 只有 0.02–0.08。穷举各 AP 活跃数、再按估计强度排序，就能拿到几乎全部收益。
  4. 估计 CSI 下：
     - 0–10 dB 时增益几乎不变（NMSE −10 dB、0 dB 时 C−A = 0.23–0.75，Ceq−A = 0.08–0.53）。M ≥ 4、β_cross ≥ 0.25 时负增益比例在 0 dB 为 ≤ 2%（Ceq−A ≤ 6%），10 dB 升到 ≤ 16%（Ceq−A ≤ 22%）；β_cross = 0.05 时 0–10 dB 为 ≤ 19%。
     - 30 dB 时残余干扰主导。均值仍显著为正：β_cross ≥ 0.25 时 C−A = 0.54–0.76（M = 4–8，−10 dB），Ceq−A 与 C−A 几乎相等（例如 M = 6、β_cross = 0.8 时为 0.57 / 0.58；完美 CSI 时为 0.53 / 0.82）。说明在残余干扰受限时多用的功率不再有用，剩下的是求逆效率部分。逐样本波动很大：29–43% 的样本为负，P10 约 −2。
     - β_cross = 0.05、30 dB 时 C−B 变为负值（−0.12 至 −0.18，−10 dB），C 的穷举过拟合了估计误差，B 更稳健（B−A 0.36–0.47 > C−A 0.23–0.30）。
  5. 对照（候选集合与 MRT 匹配）：C 从不选"AP 3 关闭"的组合（C = C_AP3）；A 在 β_cross = 0.8 时有时选 AP 1 + AP 2（A − A_AP3 = 0–0.20）。匹配候选后：
     - β_cross = 0.8 时，整 AP ZF（A_AP3）仍在所有 SNR 下高于逐天线 MRT：完美 CSI 高 1.0–11.7，−10 dB 高 0.8–3.7。而且 ZF 用的功率更少（1.73–1.80，MRT 恒为 2），所以第二轮试跑的系统比较不是功率或候选集合造成的假象。
     - β_cross = 0.05 时，0 dB 下 MRT_C 更好（A_AP3 − MRT_C ≈ −0.7，96–99% 的样本为负）；30 dB 下完美 CSI 时 ZF 更好（+1.9 至 +4.5），−10 dB 时两者接近（−0.26 至 +0.88）。
- 核心判断：同功率后逐天线选择在 ZF 下仍有稳定收益（Ceq−A 约 0.2–0.7），在低 SNR 下对 CSI 误差稳健（0 dB 负增益 ≤ 6%），10 dB 时负增益最多约 1/5；高 SNR 下均值仍为正，但约三分之一的样本为负。C−B 很小，在不完美 CSI 下还可能为负，所以不需要更强的选择算法，应优先做简单排序（B）及其更低复杂度的版本（例如替代穷举各 AP 活跃数）。可选的 RZF 补充（M = 4、6，20/30 dB，β_cross = 0.25/0.8）尚未运行。

## E8 同总天线数：单天线分布式 RU 与共址多天线 RU（same_total_20261124）

- 目的：总天线数（16）和每根天线的功率上限都相同时，比较两种部署所需的激活天线数（论文内层问题），判断"多天线 RU 上逐天线激活"这一扩展的潜力：
  - 单天线分布式 RU（K = 1），即 [10] 的逐 PRB AP 选择；
  - N = 16/K 个共址 K 天线 RU，分别做整 RU 激活和逐天线激活。

  设定由用户 2026-11-24 确认：规模和预编码按推荐，功率两种都算，逐 PRB 达标。
- 场景：
  - 天线：16 根，4 × 4 六角格，间距 40 m，区域 160 m × 138.56 m。即 EuCNC 8 × 8 布局在同密度下缩小，编号沿用 dynamic_split/cfsim.py。
  - 部署：K ∈ {1, 2, 4, 8}，RU r 由编号连续的 K 根天线组成（EuCNC 分组），共址于这些格点的质心。K = 1 即 16 个单天线 RU（D1）。
  - UE：U = 4，在区域内均匀撒点。
  - 大尺度：ITU-R M.2135-1 UMi 路损、UMi LOS 概率、对数正态阴影 3/4 dB、天线增益 2.15 dBi；同一 RU 的天线共享 β。
  - 小尺度：i.i.d. CN(0, 1)，各 PRB 独立。
  - 无线参数：4 GHz，P_max = 10 dBm/PRB/天线，噪声 −90/−70/−50 dBm/PRB（各 UE 相同）。
  - 理想 CSI、理想前传，SE 用 Shannon 公式。
  - 样本：500 个撒点 × 4 个 PRB。
- 方案：只做 ZF（论文式 (zf)）。粒度分 RU 级（每个 RU 全开或全关）和天线级（任意子集），都对 |S| ≥ U 的全部 64,839 个子集穷举。两种功率规则都算：
  - `ant`：逐天线上限，c² = P_max / max_j q_j；
  - `ru`：论文式 (norm)，c² = min(m P_max / Σq, K P_max / max_n q_n)。
- 指标：逐 PRB 解内层问题。SE_max 取 RU 级激活的最大 sum SE，M̂_g 是满足 SE ≥ 0.98·SE_max 的最小激活数。报告以下各量，判断潜力以 `ant` 规则为准：
  - ΔM̂ = M̂_RU − M̂_ant：按撒点配对的均值与 95% t 区间，以及 ΔM̂ > 0 的 PRB 比例；
  - 16 − M̂_D1；
  - SE_max(K) / SE_max(K = 1)；
  - m = 8 时的 SE_ant − SE_RU。
- 随机数：
  - UE 位置：`default_rng([20261124, d, 0])`；
  - 部署 K 的 LOS 与阴影：`default_rng([20261124, d, 1, K])`；
  - 小尺度：`default_rng([20261124, d, 2])`，各 K 共用，天线 j 在各 K 下用同一组随机数。
- 命令：`python test_same_total.py`，然后 `python run_same_total.py --drops 500 --prbs 4 --workers 48`，作图 `python plot_same_total.py`（fig_mhat_vs_K、fig_se_vs_m）。
- 验收（运行前通过，见 test.log）：
  - 布局是 cfsim 格点的左下 4 × 4 块；
  - 路损与 cfsim 逐点相同，β 与 cfsim.drop 逐位相同；
  - 各 K 共用小尺度随机数；
  - 单 UE 解析值 c² = P_max m² a²；
  - 手算例子 q = [1, 0.25]；
  - 快速穷举与逐候选伪逆一致（最大相对差 2.6e-10）；
  - 20 个撒点上的顺序、M̂ 与功率约束。
- 状态：完成（2026-11-24，48 进程 61 s）。运行检查：
  - 显式验算 312,000 个胜出子集，c² 最大相对差 5.5e-13，ZF 残差 1.4e-12；
  - 功率越界 0，天线级低于 RU 级 0，秩不足候选 0。
- 结论：以 `ant` 规则为准，数值按噪声 −90/−70/−50 dBm 列出。95% 区间半宽 ≤ 0.16，ΔM̂ > 0 的 PRB 占 89–99%。

  | | K = 1（D1） | K = 2 | K = 4 | K = 8 |
  |---|---|---|---|---|
  | M̂_RU | 7.04 / 8.03 / 9.17 | 9.38 / 10.31 / 11.12 | 12.50 / 13.32 / 13.77 | 15.74 / 15.86 / 15.89 |
  | M̂_ant | 同上 | 7.33 / 8.33 / 9.34 | 7.97 / 9.08 / 9.83 | 10.20 / 11.19 / 11.52 |
  | ΔM̂ | 0 | 2.06 / 1.98 / 1.79 | 4.54 / 4.25 / 3.94 | 5.54 / 4.66 / 4.36 |
  | SE_max / SE_max(K = 1) | 1 | 0.96 / 0.92 / 0.88 | 0.83 / 0.69 / 0.61 | 0.54 / 0.30 / 0.24 |

  1. 单天线分布式分组本身相对全开省 16 − M̂_D1 = 8.96 / 7.97 / 6.83 根激活天线。
  2. 共址以后，整 RU 激活几乎省不下天线：
     - K = 4 时 86–95% 的 PRB 要开 3 或 4 个 RU；
     - K = 8 时几乎总是全开。
  3. 逐天线激活基本恢复到单天线分布式的激活数：
     - M̂_ant 比 M̂_D1 多 0.17–0.30（K = 2）、0.67–1.05（K = 4）、2.4–3.2（K = 8）；
     - ΔM̂ 占 M̂_RU 的 16–22%（K = 2）、29–36%（K = 4）、28–35%（K = 8）；
     - K = 4 时 ΔM̂ 是 16 − M̂_D1 的 51–58%，K = 2 时是 23–26%。

     按设计时约定的标准（ΔM̂ 与 16 − M̂_D1 同一量级），扩展有潜力，K = 4（4T4R）时最明显。
  4. 机制：
     - K = 4 时，天线级的解平均保留 3.3–3.5 个站点（共 4 个），其中 2.2–2.5 个只开部分天线。也就是保留站点（宏分集），每个站点少开几根。
     - 整 RU 激活要少开天线只能关掉整个站点：m = 8（K = 4 时即 2 个 RU）时，天线级的 SE 比 RU 级高 26% / 66% / 165%。
     - 本轮没有单独分离"RU 内挑哪几根"的小尺度增益；i.i.d. 瑞利对这一部分最有利。
  5. 天线级几乎不提高 SE 上限：天线级最大 SE 只是 RU 级 SE_max 的 1.001–1.012 倍。收益全在激活天线数上，即 7-1 的 U-plane 负载。
  6. 部署本身的代价逐天线激活改变不了：天线数相同时，共址以后 SE_max 降低（见表）。M̂ 是相对各自 SE_max 计算的，所以 K = 4、8 达到的绝对 SE 更低。
  7. `ru` 规则（论文式 (norm)）：
     - ΔM̂ 在 K = 2、4 时与 `ant` 接近（2.29–2.43、3.78–4.40），K = 8 时小一些（2.48–4.17）；
     - SE_max 偏高：K = 2 时是 K = 1 的 1.01–1.18 倍，K = 4 时 0.84–1.00；
     - 原因：在 M̂ 处，RU 级和天线级 100% 的解都有天线超过 P_max（单天线最大功率平均为 P_max 的 1.5–2.6 倍，最高 6.6 倍），实际功放做不到。

     论文的式 (poru) 和 (norm) 用于共址多天线 RU 时应改为逐天线约束，待用户决定。
  8. 场景对比：单天线 RU（K = 1）与多天线 RU（K > 1）。两者都是 16 根天线、逐天线 P_max，用户 11-24 关心的是这一对比。数据取自 rows.jsonl 的 `curve_mean_se` 与 M̂。
     - SE：多天线 RU 在同样激活数下总是更低，K 越大、噪声越大差距越大：
       - 全开时：为单天线 RU 的 0.88–0.96（K = 2）、0.61–0.83（K = 4）、0.24–0.54（K = 8）；
       - 同样开 8 根、逐天线开关：0.86–0.96 / 0.57–0.82 / 0.20–0.51；
       - 同样开 8 根、整 RU 开关：0.72–0.93 / 0.22–0.65 / 0.04–0.27。
       逐天线开关不能缩小这部分差距，属于部署本身的代价。
     - 激活天线数：达到各自 98% 上限，单天线 RU 需 7.0–9.2 根。多天线 RU 整 RU 开关需 9.4–15.9 根，逐天线开关需 7.3–11.5 根（K = 4 时只多 0.7–1.1 根）。
     - 本轮没有计入每个 RU 的固定开销 γ 和站点成本，这两项对少而大的 RU 有利。
- 局限：
  - 规模与模型：16 根天线，U = 4，只做 ZF；
  - 理想 CSI，Shannon SE；
  - 逐 PRB 达标，比论文的 PRB 平均达标严；
  - RU 内天线 i.i.d. 瑞利，没有相关性；
  - 没有 MRT。
