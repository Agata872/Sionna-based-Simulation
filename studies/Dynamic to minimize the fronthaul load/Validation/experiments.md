# Validation 实验索引

研究问题：在每个 PRB 上，活跃天线数、总发射功率、每 AP 功率上限和参与传输的 UE 集合都固定时，从整 AP 选择扩展到逐天线选择能增加多少 sum SE。锚点论文：Girycki 等，IEEE TWC 23(5) 2024（[10]）。

代码：
- `antsel.py`：按 AP 预计算各天线子集的复数接收幅度，再组合成完整候选（与直接穷举等价）。
- `test_antsel.py`：验收检查，运行 `python test_antsel.py`。
- `run_round1.py`：第一轮仿真。

## E1 第一轮 MRT（round1_mrt_20261119）

- 目的：在受控设定下比较 A（AP 级穷举）、B（穷举每 AP 激活数，按服务链路 |h|² 取最强天线）、C（天线级穷举）。
- 设定：N = 3 AP、U = 2 UE。AP 1、AP 2 固定服务 UE 1，AP 3 固定服务 UE 2。M = 1, 2, 4, 6，K = 2M，P_total = 2，P_max = 1，p[n] = P_total·|S[n]|/K。服务链路 β = 1，干扰链路 β ∈ {0.05, 0.25, 0.8}，SNR ∈ {0, 10, 20, 30} dB，每组 1000 个样本。每 AP 用单位范数 MRT，同一数据流先加复数幅度。
- 随机数：样本 s 用 `default_rng([20261119, s])` 生成 M = 8 的信道，再取前 M 根；A/B/C 与 12 组 (β, SNR) 共用同一样本。每组参数各自求 argmax。
- 验收（运行前已通过）：4 AP 确定性例子 A = 4.2309544348、C = 8.7846348456；C 的可行候选数为 2/14/494/18563/735470（M = 1/2/4/6/8）；M = 2 时快速算法与直接穷举逐样本一致（最大差 4e-14）；M = 1 时 A = B = C 逐位相等；C ≥ B ≥ A。
- 命令：`python run_round1.py --M 1 2 4 6 --samples 1000 --workers 48`
- 结果目录：`results/round1_mrt_20261119/`，包括 metadata.json、src/、rows.jsonl、samples_M*.npz、summary.md 和 run.log。
- 状态：完成（2026-11-19）。48 进程下，M = 1/2/4/6 分别耗时 0.2/0.2/0.2/1.0 s。M = 8 的候选数约为 M = 6 的 40 倍，估计约 40 s。
- 运行检查：全部 1000 × 12 × 4 个（样本 × 参数 × M）组合都满足 C ≥ B ≥ A，没有违反；M = 1 时 A = B = C 逐位相等；没有不可行样本（映射固定，AP 3 总能服务 UE 2）。
- 结论（平均差值，单位 bit/s/Hz，按 M = 2/4/6 列出，95% 配对 t 区间半宽均不超过 0.16）：

  | β | SNR | B−A | C−B | C−A | C−A % (M=6) |
  |---|---|---|---|---|---|
  | 0.05 | 0 | 0.23 / 0.35 / 0.43 | 0.00 / 0.00 / 0.00 | 0.23 / 0.35 / 0.43 | 7.7 |
  | 0.05 | 30 | 1.05 / 1.61 / 1.78 | 0.72 / 2.50 / 4.00 | 1.77 / 4.10 / 5.79 | 36.1 |
  | 0.8 | 0 | 0.38 / 0.55 / 0.60 | 0.06 / 0.12 / 0.23 | 0.43 / 0.67 / 0.83 | 17.8 |
  | 0.8 | 30 | 1.26 / 2.19 / 2.59 | 0.93 / 3.46 / 6.15 | 2.19 / 5.65 / 8.74 | 101.6 |

  1. 天线级增益没有随 M 减小。在每组 (β, SNR) 下，C−A 的绝对值都随 M 增大。噪声受限时（β = 0.05、0 dB），C−B ≈ 0，C−A = B−A，相对增益稳定在约 7.5%，与顺序统计量的估计一致（M = 6 时能量比 1.35）。
  2. B−A（重新分配激活数，并按服务链路强度挑天线）在全部设定下为 0.2–2.6 bit/s/Hz。
  3. C−B 只在低 SNR 且干扰弱时可以忽略。它随 SNR、β 和 M 迅速增大，在高 SNR 下占 C−A 的大部分（β = 0.8、30 dB、M = 6 时为 6.15 / 8.74）。这部分收益来自在几万个子集里组合搜索泄漏近似抵消的子集：它依赖所有干扰链路的精确瞬时 CSI，和 ZF 的前提相同；它随 M 增长，反映的是候选数的指数增长。因此判断"干扰感知选天线"是否值得做，应与同一组活跃天线上的 ZF/RZF 比较，并检查非理想 CSI 下还剩多少。
  4. 诊断：M = 6 时，C 几乎总是同时使用 AP 1 和 AP 2（≥ 99.7%）。在这些样本里，k3 = M 只占 4–17%，大多数解同时减少了 AP 3 的天线。B 同时使用两个 AP 的比例为 82–100%，其中 k3 < M 占 65–83%。低 SNR 下 C 最常选 (3,4,5)/(4,3,5)，高 SNR 下最常选 (4,4,4)。
